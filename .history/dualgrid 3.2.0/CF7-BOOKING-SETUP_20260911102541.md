# Contact Form 7 setup for Tour Booking modal

## 1. Configure the booking form ID

The plugin now supports a dedicated booking popup opened from "Book this tour" buttons inside the tour detail modal.

Use either option:

- Global default in code: update `dg_get_booking_cf7_id()` in `includes/shortcodes.php`.
- Per shortcode override: `[tour_booking_form cf7_id="123"]`.

If no ID is configured, the modal still appears and shows a setup message.

## 2. Suggested CF7 Form markup

Paste this in the CF7 "Form" tab:

```text
<div class="we-form-grid">
  <div class="we-form-field">
    <label>Full name *</label>
    [text* your-name autocomplete:name]
  </div>
  <div class="we-form-field">
    <label>Email address *</label>
    [email* your-email autocomplete:email]
  </div>
  <div class="we-form-field">
    <label>Phone / WhatsApp *</label>
    [tel* your-phone autocomplete:tel]
  </div>
  <div class="we-form-field">
    <label>Country of residence *</label>
    [text* your-country]
  </div>
  <div class="we-form-field">
    <label>Preferred travel date *</label>
    [date* preferred-date-start min:today autocomplete:off]
    <small>Select a date using the native calendar picker.</small>
  </div>
  <div class="we-form-field">
    <label>Alternative date (optional)</label>
    [date preferred-date-alt min:today autocomplete:off]
  </div>
  <div class="we-form-field">
    <label>Travelers *</label>
    [number* travelers min:1 max:20]
  </div>
</div>

<div class="we-form-field we-form-full">
  <label>Special requests</label>
  [textarea booking-notes 6x40]
</div>

[hidden tour-id]
[hidden tour-name]
[hidden booking-type]
[hidden page-url]
[hidden page-title]

[submit "Request booking"]
```

- To: your operation inbox

- Subject: Booking request | [tour-name] | [your-name]

## 4. Rendering behavior

- `we_tours` now renders the booking modal automatically.
- The booking modal is also injected globally in `wp_footer` as a fallback.
- The JS automatically fills hidden tags for tour context when the user clicks "Book this tour".

## 5. Delivery

If messages are not delivered, configure SMTP (WP Mail SMTP or equivalent) using the same domain as the "From" address.
